# 광물분석팀 시험업무 대시보드

기존 디자인을 유지한 엑셀 분리형 독립 실행 HTML입니다. 실제 의뢰 데이터는 HTML과 저장소에 포함하지 않습니다.

## 실행

1. `index.html`을 내려받아 Chrome 또는 Edge로 엽니다. 별도 설치나 서버가 필요 없습니다.
2. 상단의 **엑셀 불러오기**를 눌러 PC의 LIMS 엑셀 파일을 선택합니다.
3. 월별·담당자별 통계와 업무 관리의 상세 목록을 조회합니다.

GitHub의 파일 화면은 HTML 소스를 보여 줍니다. 실행하려면 파일을 내려받거나, 별도로 설정된 GitHub Pages 주소를 이용하세요. 이번 변경은 Pages 설정을 바꾸지 않습니다.

## 엑셀 보관과 데이터 처리

- **GitHub에는 HTML만 올리면 됩니다. 엑셀을 함께 올릴 필요가 없습니다.**
- 엑셀은 PC의 어느 폴더에 보관해도 됩니다. HTML과 같은 폴더에 둘 필요가 없습니다.
- 선택한 엑셀은 브라우저 메모리에서 처리하며 서버나 GitHub로 전송하지 않습니다.
- 새로고침하거나 다시 접속하면 엑셀을 다시 선택해야 합니다.
- 장기 미완료 사유 메모는 같은 브라우저의 로컬 저장소에만 남으며 다른 PC와 공유하거나 LIMS에 반영하지 않습니다. 필요한 경우 CSV로 내보내세요.

## 화면

- **통합 대시보드**: 선택 월 접수·완수 실적, 현재 미완료, 접수군 완수율, 지도 윤곽, 상태 도넛, 월별 추이, 시료물질 구성, 담당자별 현황
- **월별 시험통계**: 월 선택, 시료물질·시험항목별 구성과 통계표
- **시험자별 시험통계**: 공동 담당 의뢰의 현재 상태와 담당자·항목 포함 의뢰 비교
- **지적별 의뢰현황**: 공개 위경도로 확인한 광산을 실제 좌표 지도에 표시. 광산 선택·표식 포커스·마우스로 제목 묶음별 의뢰 통계와 좌표 출처 조회
- **상단 업무 관리**: 기간·담당자·시험항목 필터, 상세 검색 후 Enter, CSV 내보내기, 장기 미완료 검토, 원자료와 요약 시트 대조

## 엑셀 구조

상세 시트는 이름과 관계없이 `작업번호`와 `시험번호` 열로 찾습니다. 필수 열은 `작업번호`, `작업ID`, `담당자`, `작업요청일`, `결과완수일`, `작업완수여부`, `시험번호`, `시험항목`, `시료번호`, `시료ID`, `시료분류`, `시료물질`입니다.

월별 요약 시트가 있으면 `월`, `작업요청수`, `결과완수작업수`를 이용해 대조합니다. 같은 이름의 `작업요청수` 열이 여러 개면 마지막 열을 월별 요약으로 사용합니다. 현재 월 선택 화면은 2026년 데이터용입니다.

## 집계 기준

- 의뢰 = 작업번호 고유값. 작업ID가 비어 있어도 작업번호로 구분합니다.
- 시험 = 작업번호+시험번호. 시료 = 작업번호+시료번호.
- 기간 접수는 작업요청일, 기간 완수는 결과완수일 기준이며 이전 접수분의 완수를 포함합니다.
- 현재 미완료는 접수 기간과 관계없이 원자료에서 미완수 상태인 의뢰입니다. 접수에서 완수를 빼서 계산하지 않습니다.
- 접수군 완수율은 선택 월에 접수한 의뢰 중 현재 완수 상태인 비율입니다.
- 공동 담당 의뢰는 각 담당자에 포함되므로 담당자별 수치 합계와 팀 전체 고유 의뢰 수는 다를 수 있습니다.
- 담당자·시험항목을 포함하는 의뢰 수는 그 담당자의 해당 항목 수행 실적을 확정하는 값이 아닙니다.
- 광종 화면은 원본 시료물질 표기를 사용하며 공식 광종 분류를 추정하지 않습니다. 여러 값이 있는 의뢰는 각 범주에 중복 포함됩니다.
- 장기 미완료는 마지막 관측 이벤트 일자와 접수일의 달력일 차이로 검토합니다. 공식 지연 판정이 아닙니다.
- 자동 LIMS 연계, 공유 저장, AI 예측 및 자동 배분은 포함하지 않습니다.

## 지도와 라이브러리

지도 윤곽은 [southkorea-maps](https://github.com/southkorea/southkorea-maps)의 통계청 2013년 시도 경계를 이용한 원본 디자인입니다. 실제 지적 경계나 최신 행정구역이 아닙니다. Excel 읽기용 SheetJS와 아이콘용 Lucide는 HTML에 포함되어 있습니다.

## 광산별 실제 좌표 지도

- 국가광물자원지리정보망(KMRGIS)의 [공개 국내광산](https://komir.kmrgis.or.kr/kmrgis/search-service/mine.do)에서 명칭·사업자·소재지·광종을 대조한 등록 위경도를 사용합니다.
- 신예미는 [한덕철광산업의 공개 사업장 약도](https://www.smhanduk.co.kr/introduction/map)의 정선 사업장 지점입니다. 서울 사무실 지점은 사용하지 않습니다.
- 등록 좌표는 광산 대표지점이며 개별 갱구 실측 위치나 광구 경계가 아닙니다.
- 좌표를 확인하지 못했거나 동명 광산을 구별할 수 없는 항목은 지도, 광산 선택 및 광산 표에서 제외합니다. 예시 좌표·시군 중심점·예전 수동 지정 위치는 사용하지 않습니다.
- 표식은 위경도에 고정됩니다. 겹침을 피하려고 위치를 옮기지 않으며 지도 확대나 광산 선택으로 구별합니다.
- OpenStreetMap 데이터를 유지하며 [OpenFreeMap](https://openfreemap.org/)의 공개 Liberty 벡터지도로 배경을 제공합니다. Leaflet 1.9.4, MapLibre GL JS 5.12.0 및 Leaflet 어댑터 0.1.3은 HTML에 포함합니다. 인터넷과 WebGL 그래픽 기능이 필요합니다. 연결되지 않으면 내장 통계청 2013 시도 윤곽과 좌표·통계는 계속 표시합니다.
- 기존 tile.openstreetmap.org의 이미지 타일을 요청하지 않습니다. 따라서 해당 서버가 반환한 ‘403 Access blocked’ 이미지가 배경에 반복되는 경로를 제거했습니다. 카카오 지도는 사용하지 않습니다.
- 배경지도에 OpenFreeMap·OpenMapTiles·OpenStreetMap 출처를 표시합니다. HTTP 브라우저에서 지도·광산 팝업·모바일 화면을 확인하고, 파일 출처(Origin: null)에 대한 지도 서비스의 CORS 허용도 별도로 확인했습니다. 자동 검사 브라우저 정책상 file:// 직접 열기 화면 검사는 수행하지 못했습니다.
- 광산 통계는 업로드 전체를 기준으로 하며 월·담당자 필터와 별개입니다. 여러 광산이 함께 의뢰된 건은 각 광산에 포함합니다.
- 분석-1, -2, -3, -4는 분석 한 줄의 4건으로 묶습니다. 실제 건수는 서로 다른 작업번호 수이며 시험·시료 행은 중복으로 세지 않습니다.
- 연도, 1차·2차 및 시추공 식별자는 유지하며 하단 상세 표에서 묶인 원제목을 확인합니다.
- 공개 위치 참고자료는 HTML에 포함하지만 실제 엑셀과 집계 결과는 포함하지 않습니다.

## 월 접수 사내·사외 구분

1. 통합 대시보드에서 해당 월 접수 카드를 클릭합니다.
2. 사내·사외·미분류 건수를 확인합니다.
3. 각 구분의 건수를 클릭하면 작업ID·의뢰제목·접수일 목록이 해당 구분으로 바뀝니다. 전체 의뢰 버튼으로 전체 목록을 표시합니다.
4. 닫기 또는 Escape로 대시보드로 돌아갑니다.

작업ID 코드의 첫 글자 I는 사내, O는 사외입니다. 예를 들어 IM·II는 사내, OM·OI·OW·OS·OC는 사외로 집계합니다. 작업ID가 없거나 코드를 판별할 수 없으면 미분류로 표시합니다. 작업요청일이 선택 월에 포함된 작업번호 고유값을 세며 공동 담당·시험·시료 행 때문에 건수가 늘어나지 않습니다.
