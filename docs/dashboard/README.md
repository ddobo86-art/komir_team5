# 광물분석팀 시험업무 대시보드

현재 디자인 시안의 독립 실행 HTML입니다.

## 실행

`index.html`을 내려받아 Chrome 또는 Edge로 여세요. 별도 빌드, 패키지 설치, 서버가 필요 없습니다. GitHub 파일 화면은 HTML을 실행하지 않고 소스 코드를 보여 줍니다.

## 화면

- **통합 대시보드**: 선택 월 접수·완수·진행 중·완수율, 한국 지도, 진행 현황 도넛, 월별 접수·완수 추이, 광종 구성, 시험자별 현황
- **월별 시험통계**: 1~12월 선택, 광종별·시험항목별 도넛과 막대 비교, 통계표
- **시험자별 시험통계**: 완수·진행 중 누적 막대, 시험자×시험항목 히트맵, 담당 의뢰 및 완수율 표, 개인별 상세
- **지적별 의뢰현황**: 지도 표식 선택 후 지적별 의뢰건수 및 시험항목 확인

## 데이터 기준

- 모든 수치, 시험자 A~E, 지적 A~C의 위치는 디자인 확인용 가상 예시입니다.
- 월별 완수는 해당 월 접수 의뢰 중 완수한 건수입니다. 이전 월 접수를 포함한 당월 전체 완수 실적과 구분됩니다.
- 완수율 = 해당 월 접수 중 완수 ÷ 해당 월 접수입니다.
- 예시는 의뢰당 대표 광종·대표 시험항목 1개 및 시험자 단독 담당을 가정합니다. 실제 시험항목 수 및 공동 담당 집계 기준은 별도로 정해야 합니다.
- 실제 Excel 파일 읽기, LIMS 연동, 사용자 인증 및 실데이터 저장은 포함하지 않습니다.

## 지도 출처

지도 윤곽은 [southkorea-maps](https://github.com/southkorea/southkorea-maps)의 `kostat/2013/json/skorea_provinces_geo_simple.json`을 d3-geo로 투영한 시도 경계입니다. 2013년 경계이며 실제 지적 경계나 최신 행정구역을 의미하지 않습니다.
