# 광물분석팀 시험업무 대시보드

기존 디자인을 유지한 엑셀 분리형 독립 실행 HTML입니다. 실제 의뢰 데이터는 HTML과 저장소에 포함하지 않습니다.

## 실행

1. `index.html`을 내려받아 Chrome 또는 Edge로 엽니다. 별도 설치나 서버가 필요 없습니다.
2. 상단의 **엑셀 불러오기**를 눌러 PC의 LIMS 엑셀 파일을 선택합니다.
3. 월별·담당자별 통계와 업무 관리의 상세 목록을 조회합니다.

GitHub의 파일 화면은 HTML 소스를 보여 줍니다. 실행하려면 파일을 내려받거나, 별도로 설정된 GitHub Pages 주소를 이용하세요. 이번 변경은 Pages 설정을 바꾸지 않습니다.

## 엑셀 보관과 데이터 처리

- **GitHub에는 HTML만 올리면 됩니다. 엑셀을 함께 올릴 필요가 없습니다.**
- 엑셀은 PC의 어느 폴더에 보관해도 됩니다. HTML과 같은 폴더에 둘 필요가 없습니다.
- 선택한 엑셀은 브라우저 메모리에서 처리하며 서버나 GitHub로 전송하지 않습니다.
- 새로고침하거나 다시 접속하면 엑셀을 다시 선택해야 합니다.
- 장기 미완료 사유 메모는 같은 브라우저의 로컬 저장소에만 남으며 다른 PC와 공유하거나 LIMS에 반영하지 않습니다. 필요한 경우 CSV로 내보내세요.

## 화면

- **통합 대시보드**: 선택 월 접수·완수 실적, 현재 미완료, 접수군 완수율, 지도 윤곽, 상태 도넛, 월별 추이, 시료물질 구성, 담당자별 현황
- **월별 시험통계**: 월 선택, 시료물질·시험항목별 구성과 통계표
- **시험자별 시험통계**: 공동 담당 의뢰의 현재 상태와 담당자·항목 포함 의뢰 비교
- **지적별 의뢰현황**: 제공된 GIS 화면을 예시 지도 배경으로 사용. 신예미 광산 표식에 마우스를 올리거나 클릭·키보드로 열면 동일 의뢰제목별 의뢰건수와 합계를 표시
- **상단 업무 관리**: 기간·담당자·시험항목 필터, 상세 검색 후 Enter, CSV 내보내기, 장기 미완료 검토, 원자료와 요약 시트 대조

## 엑셀 구조

상세 시트는 이름과 관계없이 `작업번호`와 `시험번호` 열로 찾습니다. 필수 열은 `작업번호`, `작업ID`, `담당자`, `작업요청일`, `결과완수일`, `작업완수여부`, `시험번호`, `시험항목`, `시료번호`, `시료ID`, `시료분류`, `시료물질`입니다.

월별 요약 시트가 있으면 `월`, `작업요청수`, `결과완수작업수`를 이용해 대조합니다. 같은 이름의 `작업요청수` 열이 여러 개면 마지막 열을 월별 요약으로 사용합니다. 현재 월 선택 화면은 2026년 데이터용입니다.

## 집계 기준

- 의뢰 = 작업번호 고유값. 작업ID가 비어 있어도 작업번호로 구분합니다.
- 시험 = 작업번호+시험번호. 시료 = 작업번호+시료번호.
- 기간 접수는 작업요청일, 기간 완수는 결과완수일 기준이며 이전 접수분의 완수를 포함합니다.
- 현재 미완료는 접수 기간과 관계없이 원자료에서 미완수 상태인 의뢰입니다. 접수에서 완수를 빼서 계산하지 않습니다.
- 접수군 완수율은 선택 월에 접수한 의뢰 중 현재 완수 상태인 비율입니다.
- 공동 담당 의뢰는 각 담당자에 포함되므로 담당자별 수치 합계와 팀 전체 고유 의뢰 수는 다를 수 있습니다.
- 담당자·시험항목을 포함하는 의뢰 수는 그 담당자의 해당 항목 수행 실적을 확정하는 값이 아닙니다.
- 광종 화면은 원본 시료물질 표기를 사용하며 공식 광종 분류를 추정하지 않습니다. 여러 값이 있는 의뢰는 각 범주에 중복 포함됩니다.
- 장기 미완료는 마지막 관측 이벤트 일자와 접수일의 달력일 차이로 검토합니다. 공식 지연 판정이 아닙니다.
- 자동 LIMS 연계, 공유 저장, AI 예측 및 자동 배분은 포함하지 않습니다.

## 지도와 라이브러리

지도 윤곽은 [southkorea-maps](https://github.com/southkorea/southkorea-maps)의 통계청 2013년 시도 경계를 이용한 원본 디자인입니다. 실제 지적 경계나 최신 행정구역이 아닙니다. Excel 읽기용 SheetJS와 아이콘용 Lucide는 HTML에 포함되어 있습니다.

## 신예미 광산 지도 통계

- 업로드한 전체 엑셀에서 의뢰제목에 `신예미`가 포함된 의뢰를 찾습니다. 월·담당자 필터와는 별개입니다.
- 동일한 전체 제목은 하나로 묶고 각 제목의 `작업번호`를 중복 없이 셉니다. 시험·시료 행이 반복되어도 의뢰건수를 늘리지 않습니다.
- 서로 다른 전체 제목의 수와 실제 의뢰 수를 함께 표시합니다. 제목 끝의 `-1`, `-2` 등은 별개 제목입니다.
- 마우스 올리기, 키보드 포커스 또는 클릭으로 팝업을 열 수 있습니다. Escape 또는 닫기 버튼으로 닫습니다. 지도 아래에서도 같은 목록을 표로 조회할 수 있습니다.
- 지도 배경의 기호·격자는 정적 이미지이며 신예미 표식만 통계에 연결됩니다. 표식은 정선군 신동읍 일대의 예시 위치로 정확한 광구·갱구 좌표가 아닙니다.
- 지도 이미지는 HTML에 포함되어 별도 이미지 파일이 필요 없습니다. 실제 엑셀 데이터와 집계 결과는 HTML에 포함하지 않습니다.
