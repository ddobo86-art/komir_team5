# 캐보자고 화면: 키워드 검색과 영역별 자동 보기

2026년 11월 12일 업데이트입니다. 실행 파일은 [최신 대시보드 HTML](../광물분석_업무대시보드_Apple전환.html)입니다.

## 실행과 데이터 불러오기

1. 저장소에서 HTML을 다운로드해 Chrome 또는 Edge로 엽니다.
2. 상단의 ‘엑셀 불러오기’로 PC의 LIMS 엑셀을 선택합니다.
3. 연도·월·시험분야 선택값을 누르고 휠을 위아래로 움직여 선택한 뒤 ‘적용’을 누릅니다. ‘취소’는 기존 조회를 유지합니다. 연도는 ‘2026년’처럼 표시합니다.

실제 의뢰 데이터는 HTML에 포함하지 않습니다. 내장 ‘예시 데이터로 기능 보기’는 가상 데이터이며 실제 실적이 아닙니다. 선택한 엑셀은 브라우저 메모리에서 처리하고 검색도 브라우저 안에서 수행합니다. 새로고침하면 엑셀을 다시 선택해야 합니다.

## 키워드 검색

- 캐보자고 상단에서 광산명·시험항목·담당자·의뢰제목·지표 이름을 입력하고 ‘검색’ 또는 Enter를 누릅니다.
- 지표 검색은 세 영역의 제목과 관련 키워드에서 찾습니다. 예를 들어 ‘목표’는 연간 목표 달성률을 보여 줍니다.
- 의뢰 검색은 현재 선택한 연도·월·시험분야의 **접수 의뢰**에서 작업 ID, 의뢰제목, 담당자, 시험항목, 시료물질, 시료분류, 팀·시험분야를 확인합니다.
- ‘시험자 가’처럼 이름에 공백이 있어도 하나의 이름으로 찾습니다. 한 글자가 다른 설명에 우연히 포함됐다는 이유로 다른 담당자의 의뢰를 포함하지 않습니다.
- 지표 결과를 누르면 해당 차트 영역으로 이동합니다. 의뢰 결과를 펼치면 작업 ID·담당자·시험항목·시험분야·접수일·결과완수일을 확인합니다.
- 의뢰 결과는 8건씩 표시하고 ‘더 보기’로 추가 확인합니다. ‘검색 지우기’로 결과를 닫을 수 있습니다.
- 검색은 표시 영역을 찾는 기능이며 기존 지도·목표·진행현황의 집계 정의를 바꾸지 않습니다.

## 영역별 차트의 순서와 자동 보기

1. 광산별 의뢰현황
2. 선택 연도의 연간 목표 달성률 — 기본은 ‘2026년 연간 목표 달성률’
3. 월별 시험진행현황

한 번에 한 영역을 표시하며, 자동 보기 중에는 약 8초마다 다음 영역으로 이동한 뒤 처음으로 돌아옵니다. 화면을 자동으로 스크롤하지 않습니다. 보이지 않는 동안이나 다른 브라우저 탭을 보는 동안에는 순환을 멈춥니다.

마우스를 차트 영역에 올리거나 키보드로 내부를 조작하는 동안에는 멈춥니다. 영역 탭·이전·다음 버튼·검색 결과를 직접 선택하면 자동 보기가 일시정지됩니다. 다시 순환하려면 재생 버튼을 누르세요. 영역 탭은 좌우 방향키와 Home·End로도 이동할 수 있습니다.

광산 지도는 선택·확대·축소와 기존 실제 좌표를 유지합니다. 지도를 조작하는 동안 자동 전환이 방해하지 않도록 정지할 수 있습니다.

## 숫자·차트와 집계 기준

같은 차트 영역의 숫자·도넛·막대는 하나의 2초 타임라인을 공유해 함께 시작하고 함께 끝납니다. 다른 영역을 보거나 새로운 조회를 적용하면 다시 재생합니다. 애니메이션은 표시 효과이며 엑셀의 값, 계산식, 원자료, CSV 내보내기 결과를 변경하지 않습니다. 기기의 모션 감소 설정에서는 즉시 최종 값을 표시하고 자동 보기는 기본으로 정지합니다.

집계 설명은 제목 근처의 작고 테두리 없는 ‘기준’에 모았습니다. 커서를 머물리면 설명창이 부드럽게 나타나며, 클릭·키보드 포커스·Esc 닫기도 지원합니다.

기존 집계 범위를 유지합니다.

- 지도: 업로드 전체의 의뢰와 공개 확인 좌표를 사용합니다.
- 연간 목표: 선택 연도 1월부터 선택 월 말일까지 작업 ID를 중복 제외한 누적 의뢰 기준입니다. 분야 필터와 무관한 전체 목표이며 상세 정의는 해당 ‘기준’에서 확인합니다.
- 월별 시험진행현황: 선택 월에 접수한 의뢰의 현재 완수·미완수 상태입니다.

## 확인한 동작

브라우저에서 내장 가상 데이터로 확인했습니다.

- ‘목표’ 검색 → 연간 목표 지표 1개 표시
- 2026년 10월 ‘시험자 가’ 검색 → 해당 담당자 의뢰 4건 표시 및 원자료 상세 확인
- 다음 영역 → 연간 목표 → 월별 진행현황 → 광산 순환
- 자동 재생 시 영역이 바뀌고 한 번에 한 패널만 표시됨
- 새 영역에서 숫자·차트가 같은 시작 시각과 2초 종료를 공유함
- 390px 모바일 화면에서 가로 넘침 없이 탭·차트 표시
- JavaScript 구문 검사 통과 및 확인 과정의 브라우저 오류 없음
