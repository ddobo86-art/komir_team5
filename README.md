# komir_team5

## AI 활용 아이디어 과제

광물분석팀 LIMS 기반 시험업무 현황 Dashboard 구축

- 제출부서: 광물분석팀
- 담당자: 김수현
- 과제명: 「시험업무 현황 파악 및 업무 재분배 지원체계」로 광물분석팀의 업무 효율성과 대응력을 향상

### 문서 다운로드

[HWPX 문서 다운로드](https://github.com/ddobo86-art/komir_team5/raw/refs/heads/main/docs/komir_team5_AI_idea.hwpx)

한컴오피스 한글 등 HWPX 형식을 지원하는 프로그램에서 열 수 있습니다.

문서에는 개요, 문제점 및 현황, 개선 내용이 포함되어 있습니다. 첨부 이미지에서 추출해 정리한 내용을 문서화했으며, 원문 중 판독과 표현이 불명확한 문장은 문서 마지막에 참고 사항으로 표시했습니다.

## 시험업무 대시보드 디자인 시안

최신 대시보드 시안은 [docs/dashboard/index.html](docs/dashboard/index.html)에 있습니다.

- 통합 대시보드: 접수·완수·진행 중·완수율, 지적별 의뢰 지도, 월별 추이
- 월별 시험통계: 광종별·시험항목별 구성비 및 의뢰건수
- 시험자별 시험통계: 담당·완수 현황, 시험항목 히트맵, 개인별 상세

디자인 확인용 예시 데이터이며, 실제 LIMS·Excel 데이터 연결은 포함하지 않습니다. 자세한 안내는 [대시보드 README](docs/dashboard/README.md)를 참고하세요.
