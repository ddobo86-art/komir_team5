최신 실행 파일은 [광물분석_업무대시보드_Apple전환.html](광물분석_업무대시보드_Apple전환.html)입니다.

[최신 HTML 다운로드](https://github.com/ddobo86-art/komir_team5/raw/refs/heads/main/%EA%B4%91%EB%AC%BC%EB%B6%84%EC%84%9D_%EC%97%85%EB%AC%B4%EB%8C%80%EC%8B%9C%EB%B3%B4%EB%93%9C_Apple%EC%A0%84%ED%99%98.html) 후 Chrome 또는 Edge에서 여세요. 별도 설치나 서버 실행 없이 사용할 수 있으며, 실제 실적은 **엑셀 불러오기**로 PC의 LIMS 파일을 선택해 조회합니다. GitHub의 파일 화면은 실행 화면이 아닌 소스를 표시합니다.

### 이번 화면 구성

- **키워드 검색:** 지표 이름과 광산명·의뢰제목·시험항목·담당자를 검색합니다. 의뢰 검색은 현재 연도·월·시험분야에 해당하는 접수 의뢰 기준입니다.
- **영역별 자동 보기:** 광산별 의뢰현황 → 연간 목표 달성률 → 월별 시험진행현황 순으로 약 8초마다 전환합니다. 영역 탭과 이전·다음 버튼으로 직접 선택하거나 자동 보기를 일시정지·재생할 수 있습니다.
- **조회와 기준:** 연도·월·시험분야는 휠 방식으로 선택하고, 제목 옆 작은 ‘기준’에서 집계 설명을 확인합니다.
- **집계 애니메이션:** 같은 영역의 숫자와 차트가 2초 동안 함께 시작하고 함께 끝납니다. 조회 변경과 영역 전환 때 다시 재생되며 최종 값·단위·소수점을 보존합니다.
- **읽기와 조작:** Pretendard 글꼴을 내장했고, 반응형 배치·다크 모드·상단 메뉴 자동 숨김·모션 감소 설정을 지원합니다.

실제 의뢰 데이터는 이 HTML에 포함되어 있지 않습니다. 선택한 엑셀은 브라우저 안에서 처리하며 검색을 위해 서버나 GitHub에 전송하지 않습니다. 새로고침하면 파일을 다시 선택해야 합니다. 온라인 배경지도는 인터넷 연결이 필요합니다.
